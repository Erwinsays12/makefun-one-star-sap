Entry for the [One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) competition on make.fun.

## What it does

`main.ts` writes a single one-line, 1-star review from a houseplant about
its human owner to `/output/entry.txt`. The review is a fixed, hand-written
line — the competition is judged on the text itself, so the program is fully
deterministic: every run writes the same line.

> One star. I'm a monstera, not a mood lamp: he moved me six times this month chasing
> 'good light', and now I photosynthesize out of spite in a corner that gets
> eleven minutes of sun a day.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, no secrets.
